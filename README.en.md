# Xiaomi-OCR-0 local OCR plugin for DeepSeek Harness

[中文](README.md) | **English**

Runs Xiaomi's **Xiaomi-OCR-0 (0.8B)** as a local MCP tool, so the Harness agent can read screenshots, PDFs and receipts — **fully offline, zero API cost**.

One command installs the Python environment, the **1.7 GB weights (downloaded automatically)** and the Harness configuration.

---

## Quick start (3 steps)

### 1. Clone

```bash
git clone https://github.com/geolinli/dsh-xiaomi-ocr.git
cd dsh-xiaomi-ocr
```

### 2. Install (weights included)

```powershell
# Windows
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

```bash
# Linux / macOS
bash install.sh
```

The script creates `.venv`, installs the dependencies (~3 GB), **downloads the 1.7 GB weights**, and renders the plugin config. Takes 10–20 minutes; safe to re-run (the download resumes from `.part` files).

It ends with something like:

```
PASTE THIS PLUGIN DIRECTORY INTO HARNESS (Plugins -> Add plugin):
    F:\harness\work\somethingfun\dsh-xiaomi-ocr\plugin
```

### 3. Register the plugin in Harness

1. Restart DeepSeek Harness
2. Open **Plugins** in the sidebar
3. Click **Add plugin** (or **Install a third-party plugin** in the arrow menu)
4. Paste the path printed by the installer — it is the **`plugin` subdirectory**, not the repository root:

   | OS | What to paste |
   | --- | --- |
   | Windows | `F:\harness\work\somethingfun\dsh-xiaomi-ocr\plugin` |
   | Linux | `/home/you/dsh-xiaomi-ocr/plugin` |
   | macOS | `/Users/you/dsh-xiaomi-ocr/plugin` |

   That directory contains `package.json` (the plugin manifest) and `cordis.patch.yml` (generated by the installer).
5. Click **Install**. A card named "Local OCR (Xiaomi-OCR-0)" appears, switched on

Every new session then exposes the eight tools — no manual enabling per session.

## Why it is worth installing

### 1. Images never reach the API
Without it, an image either goes to a vision API (billed per image token) or the agent simply cannot see it. With it: image → local 0.8B model → a few hundred characters → context. Recognition costs nothing.

### 2. A 0.8B model that fits in 4 GB of VRAM

| Case | Input | Output | Time | Peak VRAM |
| --- | --- | --- | --- | --- |
| Photographed exam page (1280×1700) | 1221 tok | 239 tok | 40s | 1.9 GiB |
| Dense formula page (1280px) | 1232 tok | 400 tok | 77s | 1.84 GiB |
| Receipt (932×1644) | 941 tok | 301 tok | 43s | 1.8 GiB |
| Short calligraphy | 517 tok | 24 tok | 2.5s | 1.7 GiB |

### 3. One model, three jobs

| Capability | Tool | Output |
| --- | --- | --- |
| Document parsing | `ocr_image` | Markdown (tables OTSL→Markdown, formulas LaTeX, reading order) |
| Plain text | `ocr_text` | screenshots, signs, receipts |
| Field extraction | `kie_image` | JSON for the fields you name |
| Document Q&A | `vqa_image` | amounts, dates, chart readings |
| PDF | `ocr_pdf` | per-page Markdown, first 5 pages by default |
| Batch | `ocr_batch` | several images in one call, serial + cached |
| Ops | `model_status` / `model_release` | inspect usage / free VRAM now |

### 4. Defaults shaped for agent use
- **Resolution is automatic**: derived from a vision-token budget (1200), callers pass only a path
- **Compact output**: `brief` by default, capped at 6000 chars, with an explicit `truncated` flag
- **Disk cache**: identical work returns in 0 s, across sessions
- **Tables come back as Markdown**, not OTSL tags

### 5. VRAM follows the job

| Call shape | What happens | Measured |
| --- | --- | --- |
| Default (`hold=false`) | **evicted immediately** | 1957 MiB → 141 MiB |
| Explicit `hold=true` | kept for 600 s, no reload between calls | `held_seconds_left: 598.9` |
| Idle 600 s (`EXIT_IDLE_S`) | process exits, host memory returns to 0 | RSS → 0 |
| `model_release` | immediate | 141 MiB |

Multi-page work needs no `hold`: `ocr_batch` / `ocr_pdf` process every page inside a single call and release on return.

### 6. No patching of Harness
It adds one `@deepseek-ai/dsh-mcp-client` row through the plugin system Harness already ships. Uninstall = remove the plugin.

### 7. Nothing leaves the machine
Weights, inference and cache stay local; it installs even with `huggingface.co` blocked (defaults to `hf-mirror.com`). Receipts, IDs and contracts never touch a server.

## Installer options

```powershell
.\install.ps1 -Cpu                                # CPU-only torch
.\install.ps1 -ModelMirror https://huggingface.co  # different weight source
.\install.ps1 -SkipModel                           # weights already present
.\install.ps1 -RenderOnly                          # regenerate the plugin config only
```

```bash
bash install.sh --cpu --mirror https://huggingface.co --skip-model --render-only
```

## Configuration

Edit `env` in `plugin/cordis.patch.yml`, then toggle the `mcp-xiaomi-ocr` row off/on in Plugins:

| Variable | Default | Meaning |
| --- | --- | --- |
| `XIAOMI_OCR_TOKEN_BUDGET` | `1200` | vision-token budget, drives the auto resolution |
| `XIAOMI_OCR_MAX_SIDE` | `1536` | hard cap on the long edge |
| `XIAOMI_OCR_IDLE_UNLOAD_S` | `120` | fallback idle eviction |
| `XIAOMI_OCR_HOLD_S` | `600` | retention for `hold=true` |
| `XIAOMI_OCR_SINGLE_RELEASE` | `1` | release right after a one-shot call |
| `XIAOMI_OCR_EXIT_IDLE_S` | `600` | exit the process when idle; `0` = stay resident |
| `XIAOMI_OCR_BRIEF_CHARS` | `6000` | character cap in brief mode |
| `XIAOMI_OCR_DEVICE` | `cuda` | `cuda` / `cpu` |

## FAQ

**Only 4–10 tok/s?**
Windows lacks the `causal_conv1d` / `flash-linear-attention` kernels, so linear attention runs in reference PyTorch. Warm decoding measured ~65 tok/s; image prefill costs ~10 ms/token, and that dominates. Linux + vLLM is roughly an order of magnitude faster.

**Out of VRAM?**
Lower `XIAOMI_OCR_MAX_SIDE` to 1024, or reduce `XIAOMI_OCR_TOKEN_BUDGET`.

**`huggingface.co` unreachable?**
The installer defaults to `hf-mirror.com`; override with `-ModelMirror`.

**Tables print as `<fcel>` tags?**
That is OTSL. `intent="table"` / `"markdown"` convert to Markdown; `ocr_text` uses a plain-text prompt and does not.

**How do I know it ran locally?**
The trailing comment in every result carries `{"device": "cuda", "cache": "miss|hit", "seconds": …}`; or call `model_status` and check `loaded` / `vram`.

**How do I uninstall?**
Remove the card in Plugins, then delete the repository directory.
